Política de Privacidad

Última actualización: mayo 2026

Datos que recopilamos

MLB Analytics AP recopila únicamente los siguientes datos necesarios para el funcionamiento del servicio:

  • ID de usuario de Telegram (chat_id) — para verificar acceso y enviar notificaciones
  • Estado de suscripción — fecha de expiración o acceso permanente
  • ID del administrador — para gestión de suscriptores

Uso de los datos

Los datos recopilados se utilizan exclusivamente para:

  • Verificar qué usuarios tienen acceso autorizado al servicio
  • Enviar resultados y análisis solicitados por el usuario
  • Gestión administrativa de suscripciones

Almacenamiento

Los datos se almacenan en un archivo JSON local en el servidor del bot. No se utilizan bases de datos externas ni servicios de terceros para almacenar información de usuarios.

No compartimos datos

No compartimos, vendemos ni transferimos datos personales a terceros bajo ninguna circunstancia.
