Política de Privacidad

Última actualización: junio 2026

Datos que recopilamos

ApuestasMLB recopila únicamente los siguientes datos necesarios para el funcionamiento del servicio:

  • ID de usuario de Telegram (chat_id e initData) — para verificar acceso a la Mini App y enviar notificaciones
  • Nombre de usuario de Telegram (opcional) — solo para identificación en comunicaciones
  • Estado de suscripción — fecha de expiración o acceso permanente
  • ID del administrador — para gestión de suscriptores

No recopilamos datos de navegación, cookies, direcciones IP, ubicación geográfica ni información del dispositivo.

Datos de la Mini App

La Mini App de Telegram utiliza el SDK telegram-web-app.js proporcionado por Telegram. A través de este SDK, recibimos únicamente el initData que contiene tu ID de usuario, nombre de usuario (si está configurado) y el idioma de Telegram. No tenemos acceso a tu número de teléfono ni a tus contactos.

La Mini App se aloja en GitHub Pages. GitHub puede registrar direcciones IP y datos de solicitud según su propia política de privacidad.

Uso de los datos

Los datos recopilados se utilizan exclusivamente para:

  • Verificar qué usuarios tienen acceso autorizado al servicio
  • Enviar resultados y análisis solicitados por el usuario a través del bot de Telegram
  • Gestión administrativa de suscripciones
  • Mostrar contenido personalizado en la Mini App

Almacenamiento y retención

Los datos se almacenan en archivos JSON locales en el servidor del bot. No se utilizan bases de datos externas ni servicios de terceros (excepto GitHub Pages para el alojamiento estático de la Mini App).

Los datos se conservan mientras la suscripción esté activa. Los datos de usuarios cuya suscripción haya expirado se eliminan dentro de los 30 días posteriores a la expiración.

No compartimos datos

No compartimos, vendemos, alquilamos ni transferimos datos personales a terceros bajo ninguna circunstancia, excepto cuando sea requerido por ley.

Tus derechos

Tienes derecho a:

  • Acceder a los datos que almacenamos sobre ti
  • Solicitar la corrección de datos inexactos
  • Solicitar la eliminación de todos tus datos (derecho al olvido)
  • Retirar el consentimiento en cualquier momento

Cómo solicitar la eliminación de datos

Para solicitar la eliminación completa de tus datos del sistema:

  • Envía un mensaje al bot con el comando /borrar o /delete
  • O contacta directamente al administrador: @AdrianAdmin

Procesaremos tu solicitud dentro de las 72 horas hábiles siguientes.

Cambios a esta política

Nos reservamos el derecho de actualizar esta política de privacidad. Los cambios serán notificados a través del bot de Telegram y la Mini App. La fecha de la última actualización se muestra al inicio de este documento.

Contacto

Para cualquier consulta sobre privacidad o para ejercer tus derechos: @AdrianAdmin
